# Глава III. Установка продукта

## 3.1 Подключение труб

Контур охлаждающей воды и вспомогательное подключение защитного газа.

**Требования к подключению и использованию:**
- Регулярно используемые газы: сжатый воздух (требуется фильтрация от масла и воды).
- Обычно используемые газы: аргон, азот, сжатый воздух (требуется фильтрация от масла и воды).

### 3.1.1 Охлаждающая вода
Подключается 6-миллиметровая трубка. Основная функция: отвод избыточного тепла через внутренний водяной контур структурного элемента при прохождении сварочного луча через полость — для обеспечения производительности сварки.

Требуется последовательное подключение трубопровода с циркуляцией воды: один вход и один выход.

### 3.1.2 Защитный газ
6-миллиметровая трубка подключается к штуцеру защитного газа с входным давлением **< 1 МПа**.

> ⚠️ После очистки оптических линз обратите внимание на метод работы.

**Инструменты:** перчатки или напальчники без пыли, ватные тампоны, изопропиловый спирт, сухой и чистый сжатый воздух.

**Порядок действий:**

2. Аккуратно зажмите боковой край линзы большим и указательным пальцами левой руки.
3. Правой рукой аккуратно протирайте переднюю и заднюю поверхность линзы в одном направлении — снизу вверх или слева направо.
4. Избегайте протирания вперёд-назад, чтобы предотвратить вторичное загрязнение.
5. Продуйте поверхность линзы сухим чистым сжатым воздухом и убедитесь, что на поверхности не осталось посторонних частиц.

## 4.3 Разборка и сборка оптических линз

### 4.3.1 Разборка и сборка коллимационной линзы

**Инструменты:** шестигранный ключ на 2 мм, ватный тампон без пыли, спирт.

> ⚠️ Разборку и сборку следует выполнять в чистом месте. При демонтаже объектива надевайте пылезащитные перчатки или напальчники.

**Этапы:**
1. Очистите всю пыль с поверхности лазерной головки.
2. Ослабьте вручную винт с шестигранной головкой M2.5, показанный на рисунке, с помощью шестигранного ключа на 2 мм.
3. Снимите коллимационный модуль горизонтально и вытяните его.
4. Закройте порт текстурированной бумагой, чтобы предотвратить попадание пыли в полость.
5. Поверните сальник на 90°, слегка нажав на него вниз, и выньте сальник, совместив два выступа слева/справа. Замените коллимационную линзу.

> **Примечание:** Ориентация установленной линзы — вогнутой и выпуклой стороной в правильном направлении.

# Глава VII. Введение в работу HMI

## 7.1 Введение в функцию HMI

Сенсорный экран — **7-дюймовый цветной TFT**. На главном интерфейсе в реальном времени отображаются: состояние входов/выходов (I/O), аварийные сообщения и состояние движения. HMI позволяет настраивать параметры лазера, сканирования, подачи проволоки и оборудования.

## 7.2 Введение в работу HMI

### 7.2.1 Настройка параметров (Параметры сканирования)

Раздел **[Параметры сканирования]** используется для настройки параметров обработки гальванометром. Система поддерживает хранение **до 9 групп параметров**.

Доступные параметры:
- **Номер параметра**: выбор сохраняемой группы (1–9).
- **Скорость сканирования**: скорость движения гальванометра (мм/с).
- **Мощность лазера**: выходная мощность при сварке (Вт).
- **Длина сканирования**: размер пятна/линии по оси X (мм).
- **Ширина сканирования**: размер по оси Y (мм).
- **Тип сканирования**: форма траектории луча. Поддерживаются: круг, прямоугольник, одиночная прямая линия, спираль (круг), множество прямых линий.
- **Количество сканирований**: максимальное число проходов при удержании кнопки «Старт». Значение `∞` означает бесконечный цикл до отпускания кнопки.

**Дополнительные параметры для линейных типов:**
- **Линейный выбор**: активация одного из четырёх типов линий (спираль, пила, точка, спиральная точка).
- **Шаг (Pitch)**: расстояние между витками для спирального режима.
- **Диаметр спирали**: диаметр для спирального режима.
- **Высота / Ширина амплитуды**: параметры для пилообразного режима.
- **Количество точек**: для точечных режимов.
- **Диаметр большой/малой окружности**: для режима «спиральный круг».
- **Количество параллельных линий / Расстояние**: для режима параллельных линий.

### 7.2.2 [Системный параметр]

Используется для настройки основных параметров оборудования. **Перед входом на страницу необходимо ввести пароль.** В дилерских материалах по данной серии упоминается пароль `666666` для доступа к смене типа обработки, однако для входа именно в «Системные параметры» проверьте фактическое значение на экране вашего устройства.

### 7.2.3 [Параметр подачи проволоки]

Используется для настройки параметров подачи и отвода проволоки (например, параметр подачи / параметр отвода).

### 7.2.4 [Параметр оборудования]

# Глава VIII. Устройства контроля и защиты

## 8.1 Настройка температурных параметров защитного стекла

Путь в меню: `[Home Page] → [System Parameter] → [Equipment Parameter] → ввод пароля: 666888 → [next page] → [lens temperature alarm limit value]`.

Рекомендуемое значение температуры линзы: **50**. После превышения этого значения на главной странице появляется предупреждение, а индикатор на боковой стороне рукоятки становится красным.

## 8.2 Мониторинг Bluetooth-приложения (RDWelder)

Приложение **RDWelder** поддерживает удалённое управление ручными сварочными головками (одинарного и двойного маятника, а также режимы очистки). Подключение к плате управления — два режима:

- **AP-режим**: плата излучает Wi-Fi-сигнал, телефон подключается напрямую. На экране HMI и в APP отображается иконка Wi-Fi.
- **STA-режим**: плата подключается к внешнему Wi-Fi и выходит в облако. На экране и в APP отображается иконка IoT-облака.

**Настройка AP-режима на плате**: нажать правый верхний угол сенсорного экрана → Wi-Fi configuration → выбрать AP → задать имя и пароль точки доступа. Если Wi-Fi уже включён, сначала нажать `<Turned On>` для выключения, затем настроить и нажать `<Turn on WIFI>`.

**Настройка APP**: запустить приложение → войти в `<Device Management>` → выбрать прямое подключение устройства → подключиться к Wi-Fi точке платы → проверить статус подключения в APP.

Функции APP: просмотр состояния оборудования, корректировка параметров, техническая библиотека (руководства, процедуры обслуживания, диагностика неисправностей, примеры применения).

# Глава X. Выбор типа обработки

## 10.1 Выбор типа обработки

Переключение режима выполняется через панель HMI:
`[Системные параметры] → [Авторизация] → [Тип обработки]`

При нажатии на «Тип обработки» система запросит **пароль: 666666**. После корректного ввода открывается интерфейс выбора типа системы (сварка, очистка 110/200/300 мм и т.д.).

## 10.2 Подсказка по замене модуля

После выбора типа обработки система выдаёт **текстовое и графическое напоминание** о компонентах головки, которые необходимо заменить. Пользователь подтверждает замену оборудования, после чего установку нужно **выключить** для физической замены соответствующего компонента.

## 10.3 Завершение переключения

После замены аппаратного компонента оборудование включается снова. Система повторно запрашивает подтверждение замены. После нажатия **[Подтвердить]** переключение режима обработки завершается.

# Глава XI. Очистка и замена сварных швов

# Глава XII. Замена накопителя энергии сварки

## 12.1 Схема замены структурной части

1. Открутите **3 винта M2.5×6 с шестигранной головкой** на сварочном газовом кольце (используйте шестигранный ключ на 2 мм).
2. Замените специализированный узел сопла для сварки накопителя энергии.
3. Установите его теми же 3 винтами M2.5×6.
